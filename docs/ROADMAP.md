# Roadmap

## Implemented foundation

- external `shipping/drydock-project.json` contract;
- development and release component verification;
- shared symlink-safe live/staged composition;
- schema-3 artifacts with releasability and provenance;
- localhost web iteration and static web builds;
- Electron staging and runtime security policy;
- checksummed direct-download packaging;
- namespaced VPS and downloads publishing;
- generic synthetic-project test coverage.

## Next channel work

- signing policy and enforcement for production desktop downloads;
- Steam, Epic, GOG, and itch integration/package/publish adapters;
- App Store and Google Play adapters;
- optional local operational-config selection where repeated explicit environment
  inputs become cumbersome;
- stronger post-publish health and rollback tooling.

All workflows remain explicit and manual. Hosted CI is intentionally out of scope until
the command contracts and release policy are proven by real game repositories.
